# FPL Intelligence — researched plan and master prompt

Prepared 29 October 2026.

The recommended product combines independent probabilistic forecasts, evidence-backed football context, exact FPL rules, correlated simulation and sequential optimization. Python handles the numerical engine; TypeScript/React handles the interface; eligible free hosted AI handles language understanding. No local LLM is required.

2. **02_COPY_READY_MASTER_PROMPT.md** — the implementation prompt. Give it to a capable coding/research agent with the rest of this package. It requires working code, real calculations, tests and measured quality.

If using the ZIP, extract all files into one project directory. Start with the blueprint; use the copy-ready prompt to commission implementation. Keep the other files available to the implementation agent.

## What makes this specification demanding

The finished system must calculate legal, affordable recommendations from versioned data; explain the evidence that changed a forecast; evaluate credible alternatives; preserve uncertain future branches; and show whether context and complexity actually improve decisions.

Top-1% competitiveness is the performance target. It must be assessed through frozen historical/prospective evidence. The package does not substitute a promised rank for that evidence.

This delivery completes the research, specification and prompt request. It does not claim that the finished predictive product has already been trained or deployed.
