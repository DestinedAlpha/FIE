# Delivery and evidence matrix (0.5)

This maps the supplied blueprint to working components. Original research documents remain unchanged. A completed implementation and a model passing its statistical acceptance test are separate facts. The machine-readable release audit in `artifacts/evaluations/release_0_5.json` records the final executed checks and artifact IDs.

| Requirement | Implementation and executed evidence |
|---|---|
| Immutable official data, identity and complete market | `ingestion` (including identity resolution), `storage`; full registry, hashes, dated captures, missingness, schema/identity tests |
| Versioned rules and actual account | `domain`, `rules`; integer purchase/sale lots, pending hits/refunds, FT, active chips, FH restoration, independent ledger replay and exhaustive small-market oracle |
| Historical/current training | Four preceding compatible seasons plus finalized current GW1–8; expanding chronological blocks and purged four-week decision windows |
| Advanced statistics | `features`, `fusion_data`, `horizon`; xG/xA, starts/minutes, scoring/defensive actions where present, missingness masks and incremental comparisons |
| Minutes and points distributions | Validated reference, multi-source trees, temporal neural challenger; calibrated minute states, empirical tails, cohort and captain/policy audits |
| Structural football worlds | `simulation`, `coherent`; finite distinct XI/substitutions, conserved goals/assists, exposure scoring, shared bonus, rate-head/BPS tests and policy sensitivity |
| Context extraction and actual source use | `research`, `intelligence`, `context`; literal source support, entity/time checks, quarantine, contradiction handling, independent source-off refits |
| Top managers and future behavior | `elite`, `manager_behavior`, `manager_policy`, `rivals`; actual top-1,000 histories, count/buy/sell/chip tests and evolving legal future branches |
| Random squads and optimal-transfer learning | `decision_training`, `strategy`; full-market legal candidate actions, four evolving deadlines, realized returns, hindsight diagnostic, tree/listwise neural critics and purged acceptance gates |
| Joint transfer/chip optimization | `optimization`, `decision_runtime`; full-market multiweek MIP, all legal chips/15-transfer range, exact financial replay, solver status/bounds/gaps, warm feasibility checks |
| Horizons and future flexibility | Purged horizon model, gated continuation model for squad/bank/FT/chips, capped training support, longer-horizon comparison |
| Original GW9–19 case families | `rivals.case_comparison` plus diverse reference/tree/neural/critic first actions; all eleven weeks and common-world frontier selection |
| Rival and overall rank objectives | Explicit hold/greedy/learned rival branches, visible EV-sacrifice constraint; actual rank-stratified population, weighting/activity tests, uncertainty and scope labels |
| Observable contingencies | `scenarios`; shared prefixes until reveal, conditional official market, full remaining-horizon recourse and price/news/fixture branches |
| Early vs wait and research priority | `market_model`, `decision_runtime`; pre-deadline price/news tests, lot-aware affordability, legal recourse in both branches and decision value of reports |
| Complete local product | Account editor, forecast/market, planner, rivals, evidence, model controls, timing/population panels, durable serial jobs, freshness, JSON/CSV/MD/ICS exports |
| Operations | Windows launcher/update, consistent SQLite backups/restore, relocated artifact resolution, preserved keys/account, CPU neural dependencies, opt-in local refresh cadence |
| Free-only and secrets | Independent optional provider authentication/free attestation, quota reservations, no paid tools, credential exclusion and decompressed-package scanning |
| Release checks | Ruff/format/mypy, backend and neural tests, TypeScript/Vite/unit tests, real API desktop/mobile browser journeys, Windows/Linux CI, verified private GitHub archive |
| Prospective competitive evidence | Freeze/score/archive machinery implemented. Future gameweek outcomes and a statistically demonstrated competitive advantage cannot be completed before those matches occur. |

Unavailable paywalled specialist data, historical news that was not captured, unobserved travel/tactical details and unreleased manager picks remain missing or explicitly hypothetical. No integration invents these inputs. Architectures that fail acceptance remain visible research challengers; accepting them merely to remove a status flag would reduce reliability.
